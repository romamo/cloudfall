## Key Findings

- Guessing `--api-key` or `--source-url` works: argparse prefix-matches the `*-file` flag and the error prints the secret, including a database password
- A watching agent sees nothing from `operator run --interval` under a pipe, and SIGTERM discards every buffered pass
- A typo in a component or release id produces a Python traceback on exit 1, the same exit code `health` uses for an unhealthy component
- `restart`, `deploy`, `rollback`, and `data migrate` act on the first CLI call, while the MCP server requires a confirm handshake for the same operations
- Output is never bounded: `inventory show` on a 600-server project returns 181 KB as one JSON line
